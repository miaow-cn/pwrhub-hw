# PWR HUB - 4-Channel DC Power Hub

A compact 4‑channel DC power distribution board built around TPS563201 synchronous step‑down converters. It accepts a wide input voltage range and generates four independent, high‑current output rails for powering FPGAs, SBCs, MCU boards, sensors, and other digital logic systems.

## Features

- Wide Input Range: 6V – 17 V DC (compatible with 12 V adapters, etc.)
- Four Independent Outputs:
  - VIN (input pass‑through)
  - 5 V @ 3 A
  - 3.3 V @ 3 A
  - 1.8 V @ 3 A
  - 1.2 V @ 3 A
- High Efficiency: Synchronous rectification with integrated 95 mΩ (high‑side) and 57 mΩ (low‑side) FETs
- Fixed 570 kHz Switching Frequency
- Eco‑mode Pulse‑Skip Control – maintains high efficiency at light loads
- 1 ms Soft‑Start
- Over‑Current & Thermal Protection
